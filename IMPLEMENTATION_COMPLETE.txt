STEP 1: Get Formspree ID (2 minutes)

3. Enter your email address

6. Give form a name (e.g., "Poetry Website Contact")
7. Click "Create"
8. Copy your ID (the part after "f/")
   Example: If endpoint is f/xyzabc123def456, your ID is: xyzabc123def456

═══════════════════════════════════════════════════════════════════════════════
                          WHAT HAPPENS WHEN USER SUBMITS
═══════════════════════════════════════════════════════════════════════════════

SUBMISSION FLOW
───────────────
1. User fills all form fields
2. Clicks "Send Message" button
3. JavaScript intercepts form submission
4. Validates all fields client-side
   ↓
   If any field invalid:
   - Shows red error messages
   - Stops submission
   - Returns to form for corrections
   ↓
   If all fields valid:
5. Shows loading spinner animation
6. Disables submit button (prevents double submission)
7. Sends form data to Formspree API
8. Formspree receives the data
9. Formspree forwards message to your email
10. Response returns to browser
    ↓
    If successful:
    - Shows green success alert
    - Clears all form fields
    - Re-enables submit button
    - Ready for next message
    ↓
    If error:
    - Shows red error alert
    - Keeps form data (user can retry)
    - Re-enables submit button

                          SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Form won't submit
SOLUTION:
1. Open browser console (F12)
2. Look for error messages in red
3. Verify Formspree ID is correct in contact-form.js
4. Try submitting again

ISSUE: Emails not received
SOLUTION:
1. Check spam/junk folder
2. Verify email address in Formspree dashboard
3. Log in to Formspree and check form submissions
4. Try submitting test email again

ISSUE: Validation errors on correct input
SOLUTION:
1. Open browser console (F12)
2. Check for JavaScript errors
3. Verify all field names are correct
4. Refresh page and try again

ISSUE: Loading spinner won't stop
SOLUTION:
1. Check browser console for errors
2. Verify Formspree ID is correct
3. Check internet connection
4. Try submitting again

For more troubleshooting, see CONTACT_FORM_SETUP.md
