## WHAT HAPPENS BEHIND THE SCENES

User fills form and clicks submit:
  ↓
JavaScript intercepts submission
  ↓
Validates all fields client-side
  ↓
If invalid: Shows errors and stops
  ↓
If valid: Shows spinner and disables button
  ↓
Sends FormData to Formspree API
  ↓
Formspree receives data
  ↓
Formspree forwards to your email
  ↓
Response returns to browser
  ↓
If success: Shows message and clears form
  ↓
If error: Shows error message
  ↓
Button re-enabled for next submission
