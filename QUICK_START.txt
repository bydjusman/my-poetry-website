QUICK START - CONTACT FORM
===========================

## 3-MINUTE SETUP

### 1. Get Your Formspree ID (1 minute)
- Visit https://formspree.io
- Sign up free
- Create new form
- Copy your form ID (after "f/")

### 2. Update JavaScript (1 minute)
- Open contact-form.js
- Find: const FORMSPREE_ID = 'YOUR_FORMSPREE_ID';
- Replace YOUR_FORMSPREE_ID with your ID
- Save file

### 3. Test It (1 minute)
- Open index.html in browser
- Go to "Get In Touch" section
- Fill form and click "Send Message"
- Check your email

Done! ✓

## WHAT HAPPENS WHEN SUBMITTED

1. JavaScript validates all fields
2. Shows error messages if invalid
3. Sends to Formspree if valid
4. Shows loading spinner
5. Success message appears
6. Email sent to you
7. Form clears automatically

## COMMON ISSUES & FIXES

No emails received?
→ Check spam folder
→ Verify email in Formspree
→ Check form submissions in Formspree dashboard

Validation errors on correct input?
→ Check browser console (F12)
→ Verify field names in HTML

Loading spinner won't stop?
→ Check Formspree ID in contact-form.js
→ Try submitting again
→ Check browser console for errors
